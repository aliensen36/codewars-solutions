# Restore IPv4Address class

**Ката:** [Restore IPv4Address class](https://www.codewars.com/kata/63a0f3f49547e9001e7ad1ca)  
**Ранг:** 4 kyu  
**Тема:** Object-oriented Programming  
**Язык решения:** Python

---

## 📋 Описание задачи

Класс `IPv4Address` был повреждён злонамеренным тимлидом. Ваша задача — восстановить утраченный код. Хорошая новость: все юнит-тесты остались нетронутыми. Однако есть подозрение, что придётся сделать что-то необычное…

Восстановление кода требует не только понимания устройства IPv4-адресов, но и анализа тестов, чтобы понять, какое именно поведение ожидается от класса.

---

## 💡 Подход к решению

Основная идея — восстановить класс `IPv4Address`, который должен корректно:
- хранить четыре октета адреса (0–255 каждый);
- поддерживать строковое и числовое представление;
- корректно обрабатывать невалидные входные данные.

Так как исходный код утерян, ключевым инструментом становится чтение тестов: именно они задают контракт класса — ожидаемые исключения, форматы вывода, поведение при сравнении и т.д.

---

## 🧠 Что проверяет ката

- Умение читать и понимать тесты как спецификацию;
- Навыки объектно-ориентированного проектирования;
- Внимательность к деталям (граничные случаи, валидация);
- Способность «достроить» поведение по его проявлениям.

---

## 🛠️ Ключевые моменты реализации

- **Валидация октетов:** каждый октет должен быть целым числом в диапазоне `0..255`;
- **Строковое представление:** формат `"a.b.c.d"`;
- **Числовое представление:** преобразование адреса в 32-битное целое и обратно;
- **Обработка ошибок:** ожидаемые типы исключений определяются по тестам.
