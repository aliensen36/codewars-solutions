# Python's Dynamic Classes #3

Задание из мира Python, уровень **5 kyu**, автор — `adam-tokarski`. Тема: **динамическое создание классов** и объектно-ориентированное программирование.

По сюжету босс приносит секретный армейский контракт: имена свойств и методов будущего класса неизвестны, но класс нужно создать программно. Твоя задача — дописать функцию `create_class`, которая по имени класса и секретному словарю строит класс «на лету».

## Что нужно реализовать

Функция `create_class(class_name, secrets)` должна:

1. **Принимать имя класса** (`str`) и **секретный словарь** (`dict`) с атрибутами — свойствами и методами.
2. **Создавать класс** из этих данных и **возвращать сам класс** (не экземпляр).
3. Если `class_name` **пустой** — возвращать `None`.
4. Позволять вызов **без второго аргумента** (то есть `secrets` должен иметь значение по умолчанию).

Словарь с атрибутами поставляется готовой функцией `army_get_secret_from_file()` — её писать не нужно.
