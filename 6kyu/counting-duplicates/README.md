# Counting Duplicates

Решение задачи [Counting Duplicates](https://www.codewars.com/kata/54bf1c2cd5b56cc47f0007a1/python) с Codewars (6 kyu).

## Описание задачи

Напишите функцию, которая возвращает количество **различных** символов (без учёта регистра), которые встречаются в строке **более одного раза**. Строка содержит только буквы (в обоих регистрах) и цифры.

### Примеры

```python
"abcde"            -> 0   # нет повторяющихся символов
"aabbcde"          -> 2   # 'a' и 'b'
"aabBcde"          -> 2   # 'a' дважды, 'b' дважды ('b' и 'B')
"indivisibility"   -> 1   # 'i' встречается 6 раз
"Indivisibilities" -> 2   # 'i' 7 раз, 's' 2 раза
"aA11"             -> 2   # 'a' и '1'
"ABBA"             -> 2   # 'A' и 'B' по два раза
```
