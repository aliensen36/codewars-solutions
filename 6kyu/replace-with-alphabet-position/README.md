# Replace With Alphabet Position

- **Ссылка:** https://www.codewars.com/kata/546f922b54af40e1e90001da/train/python
- **Сложность:** 6 kyu
- **Темы:** strings, fundamentals

## Условие

Дана строка. Нужно заменить каждую букву её позицией в алфавите (`a` = 1, `b` = 2, …, `z` = 26). Всё, что не является буквой, игнорируется и в результат не попадает. Результат — строка чисел, разделённых пробелом.

### Пример

```
Input  = "The sunset sets at twelve o' clock."
Output = "20 8 5 19 21 14 19 5 20 19 5 20 19 1 20 20 23 5 12 22 5 15 3 12 15 3 11"
```

## Ключевая идея

Позиция латинской буквы в алфавите вычисляется через её код: `ord('a')` = 97, значит `ord(char) - ord('a') + 1` даёт 1 для 'a', 2 для 'b' и 26 для 'z'. Регистр снимается через `str.lower()`, чтобы не разбирать `'A'` и `'a'` отдельно.
