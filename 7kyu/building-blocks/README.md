# Building Blocks

**Название:** Building blocks
**Уровень:** 7 kyu
**Ссылка:** https://www.codewars.com/kata/55b75fcf67e558d3750000a3
**Темы:** ООП, классы, конструктор, методы, арифметика

### Задача

Написать класс `Block`, который создаёт «блок» (прямоугольный параллелепипед) из трёх целых чисел `[width, length, height]`.

Конструктор принимает список из трёх чисел. Нужно реализовать методы:

| Метод | Что возвращает |
|---|---|
| `get_width()` | ширину блока |
| `get_length()` | длину блока |
| `get_height()` | высоту блока |
| `get_volume()` | объём |
| `get_surface_area()` | площадь поверхности |

Проверка на ошибки не требуется.

### Пример

```python
b = Block([2, 4, 6])

b.get_width()         # 2
b.get_length()        # 4
b.get_height()        # 6
b.get_volume()        # 48
b.get_surface_area()  # 88
```
