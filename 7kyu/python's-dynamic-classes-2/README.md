# Python's Dynamic Classes #2

## Описание

Продолжение ката [Python's Dynamic Classes #1](https://www.codewars.com/kata/python-s-dynamic-classes-1).

Тимми узнал от своего босса, что функция изменения имени класса — это здорово, но было бы неплохо как-то спрятать эту функцию внутри самого класса.

Тимми подумал и решил обратиться к своему гуру — к тебе — с просьбой построить класс, который можно наследовать и который предоставлял бы классовый метод для изменения имени уже существующих классов.

## Задача

Создай класс `ReNameAbleClass`, который:

1. **Может быть унаследован** другими классами.
2. Предоставляет **классовый метод** `change_class_name`, позволяющий изменить имя класса.
3. Имя класса должно содержать **только буквенно-цифровые символы** (заглавные и строчные буквы латинского алфавита, а также цифры).
4. Имя класса должно **начинаться только с заглавной буквы**.
5. Имеет метод `__str__`, возвращающий строку вида:
   ```
   Class name is: MyClass
   ```
