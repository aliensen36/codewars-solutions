# Vowel Count

## Описание задачи

Данная ката (задача) с платформы Codewars предлагает написать функцию, которая подсчитывает количество гласных букв в заданной строке.

**Уровень сложности:** 7 kyu

## Условие

Необходимо вернуть количество (count) гласных в переданной строке.

Гласными считаются буквы: **a, e, i, o, u** (буква **y** гласной не считается).

Входная строка состоит только из строчных букв латинского алфавита и/или пробелов.

## Примеры

```
"abracadabra" → 5
"pear tree"   → 4
"o a e i o u" → 6
"my pyx"      → 0
```
