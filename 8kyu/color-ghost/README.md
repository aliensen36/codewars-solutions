# Color Ghost

- **Ссылка:** https://www.codewars.com/kata/53f1015fa9fe02cbda00111a/train/python
- **Сложность:** 8 kyu
- **Темы:** object-oriented programming, fundamentals

## Условие

Нужно создать класс `Ghost` (призрак). Объекты этого класса создаются **без аргументов** — то есть при инициализации ничего передавать не нужно.

При создании каждый объект-призрак получает атрибут `color` со случайным значением из четырёх вариантов: `"white"`, `"yellow"`, `"purple"`, `"red"`.

```python
ghost = Ghost()
ghost.color  #=> "white" or "yellow" or "purple" or "red"
```

### Требования

- Класс называется `Ghost`.
- Конструктор не принимает аргументов (кроме `self`).
- У каждого созданного объекта есть атрибут `color`, значение которого выбирается случайно из списка цветов.
- Цвет фиксируется в момент создания объекта — при повторном обращении к `ghost.color` он уже не меняется.

## Ключевая идея

Класс в Python объявляется через `class Ghost:`, а начальные значения атрибутов объекта задаются в методе `__init__`, первым параметром которого всегда идёт `self`. Внутри `__init__` присваивание вида `self.color = ...` создаёт атрибут именно у **экземпляра** (конкретного объекта), а не у класса — поэтому у разных призраков цвета независимы.

Случайный выбор элемента из последовательности удобно делать функцией `choice` из модуля `random`: `choice(["white", "yellow", "purple", "red"])` возвращает один случайный элемент списка. Важно импортировать функцию правильно — `from random import choice` (тогда обращаемся к `choice` напрямую) или `import random` (тогда пишем `random.choice`). Частая ошибка новичков — `from random import random`, что импортирует функцию-генератор числа, а не модуль, и у неё нет метода `.choice`.

Ещё один нюанс: `choice` принимает **одну** последовательность, поэтому цвета нужно передавать списком (или кортежем), а не четырьмя отдельными аргументами.
