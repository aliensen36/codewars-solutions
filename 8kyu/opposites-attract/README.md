# Opposites Attract

- **Ссылка:** https://www.codewars.com/kata/555086d53eac039a2a000083/train/python
- **Сложность:** 8 kyu
- **Темы:** fundamentals

## Условие

Тимми и Сара думают, что влюблены, но узнают наверняка, только когда сорвут по цветку. Если у одного цветка чётное число лепестков, а у другого — нечётное, значит, они влюблены.

Нужно написать функцию, которая принимает количество лепестков у двух цветков и возвращает `True`, если они влюблены, и `False`, если нет.

### Пример

```
lovefunc(2, 3)  -> True   # чёт + нечёт = влюблены
lovefunc(2, 4)  -> False  # чёт + чёт = не влюблены
lovefunc(3, 5)  -> False  # нечёт + нечёт = не влюблены
lovefunc(0, 1)  -> True   # 0 чётное, 1 нечётное = влюблены
```

## Ключевая идея

Чётность числа проверяется остатком от деления на 2: `x % 2 == 0` — чётное, иначе нечётное. Вместо того чтобы проверять чётность каждого цветка отдельно, можно сложить оба числа: **сумма чётного и нечётного всегда нечётная**, а сумма двух чётных или двух нечётных — всегда чётная. Значит, достаточно проверить `(flower1 + flower2) % 2 != 0` — это и будет ответ. Ноль считается чётным, поэтому `lovefunc(0, 1)` корректно возвращает `True`.
